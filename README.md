# 🧠 AI Learning Path Planner

> **AI-powered path planner that crafts personalized learning journeys based on your goals and skill level.**

## 📌 Overview

The AI Learning Path Planner is an intelligent tool that helps users discover customized learning roadmaps in the field of Artificial Intelligence. Whether you're a beginner or intermediate learner, this project curates step-by-step content tailored to your goals — be it becoming a data scientist, ML engineer, or research intern.

## 🚀 Features

- 🎯 Personalized path generation based on user input
- 📚 Curated topics: ML, DL, NLP, CV, Math for AI
- 🔍 Dynamic topic suggestion with relevance scoring
- 🧩 Modular learning (Beginner → Intermediate → Advanced)
- ⚡ Interactive UI built using Streamlit

## 🛠 Tech Stack

- **Frontend/UI**: Streamlit
- **Backend**: Python
- **AI/NLP**: GeminiAI 

## 🧑‍💻 How It Works

1. User provides:
   - Current skill level
   - AI domain of interest
   - Learning duration & time availability
2. Model analyzes gaps and maps relevant modules
3. A personalized roadmap is generated with:
   - Recommended sequence
   - Resources (videos, blogs, papers)
   - Timeline suggestions
